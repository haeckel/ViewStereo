ViewStereo ヘルプ

ViewStereo（ビューステレオ） は、19世紀の歴史的ステレオカード（Stereoview / Stereograph）および現代のステレオ写真を、最先端のCore MLと数理幾何最適化によって自動検出・位置調整・ステレオウィンドウ調整し、高品位なデジタル写真（空間写真 / SBS / アナグリフ等）に復元・変換するスタジオアプリケーションです。

主な機能

  • ステレオカード自動検出・分割 (Card Segmentation): 台紙付きステレオカードをドロップするだけで、Core ML（StereoCardSeg + MobileSAM / SAM 2.1 Tiny）が左右の写真領域およびアーチ型（Arch-top）枠を高精度に認識・抽出します。
  • 7自由度対称ホモグラフィ最適化: 手貼りによる回転・スケール差・キーストーン・垂直視差を LAPACK dposv_ ＋ IRLS でサブピクセル精度に完全解消します。
  • インテリジェント・ステレオウィンドウ決定: 最前景（最近接被写体）を基準にステレオウィンドウを自動設定し、目への負担（網膜闘争・ウィンドウバイオレーション）を防止します。
  • MAAIR 最大共通内接矩形: 幾何補正後の左右領域から有効領域を最大化した共通矩形を算出して自動トリミングします。
  • ヴィンテージ復元 & カラーマッチング: 左右レンズの露光差や経年褪色を自動補正し、自然な立体視を実現します。
  • Apple Vision Pro 空間写真（Spatial Photo）出力: 最新の空間写真フォーマット（HEIC）やVR向けSBS、3Dモニター、アナグリフへワンクリック書き出しできます。

ショートカット

  • ⌘O: ステレオカード画像、左右ペア画像、または SBS 画像を開く
  • ⇧⌘A: 自動カード検出・位置合わせ＆ウィンドウ決定を実行
  • X: 左右画像のスワップ
  • ⌘1 / ⌘2 / ⌘3: Alignment / Window / Export タブ切替
  • ⇧⌘B: フォルダ一括バッチ処理
