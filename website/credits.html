謝辞 / Acknowledgments

使用しているオープンソースソフトウェア & AI技術

本プロジェクトは、以下の優れたオープンソースソフトウェア、AIモデル、および Apple フレームワークを活用して開発されています。

SAM 2.1 (Segment Anything Model 2.1 Tiny)
Meta AI (FAIR) が開発した高精度セグメンテーション基盤モデルです。劣化や変色のある歴史的ステレオカードの印画枠・アーチ境界を正確に抽出するために使用しています。（Apache License 2.0）
Meta SAM 2 GitHub リポジトリ

MobileSAM (Faster Segment Anything)
Chaoning Zhang 氏らによって開発された軽量高速な Vision Transformer ベースのマスク精密化モデルです。Apple Silicon 上で高速にステレオカードの枠領域をリファインするために使用しています。（Apache License 2.0）
MobileSAM GitHub リポジトリ

StereoCardSeg (Core ML U-Net) & StereoCore (7-DoF Alignment)
ステレオカード左右写真領域およびアーチ幾何パラメータを初期検出する Core ML モデルと、Apple Accelerate LAPACK (dposv_ + IRLS) を用いた7自由度対称ホモグラフィ整準・MAAIR 最大共通内接矩形クロップエンジンです。

StereoStudioCore & Apple Frameworks
Stereo Creative Studio シリーズ共通基盤パッケージに加え、Apple Core ML、Vision (OCR / Saliency / Person Segmentation)、Accelerate、ImageIO、AVFoundation (MV-HEVC Spatial Photo) を活用しています。

Open Source Software & AI Technologies

ViewStereo is built upon the following remarkable open-source software, AI models, and Apple system frameworks.

SAM 2.1 (Segment Anything Model 2.1 Tiny)
Developed by Meta AI (FAIR). Used as a high-precision mask refiner for complex or aged historical stereoview borders. (Apache License 2.0)
Meta SAM 2 GitHub Repository

MobileSAM (Faster Segment Anything)
Developed by Chaoning Zhang et al. Used for fast, lightweight Core ML mask refinement of stereoview print boundaries and arch-top frames. (Apache License 2.0)
MobileSAM GitHub Repository

StereoCardSeg & StereoCore
Custom U-Net Core ML localization combined with 7-DoF symmetric homography alignment (LAPACK dposv_ + IRLS) and MAAIR optimal cropping.

StereoStudioCore & Apple Frameworks
Powered by the shared StereoStudioCore framework alongside Apple Core ML, Vision (OCR, Saliency, Person Segmentation), Accelerate, ImageIO, and AVFoundation (MV-HEVC Spatial Photo).
