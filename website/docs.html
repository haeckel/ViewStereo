1. 概要と特長

ViewStereo（ビューステレオ） は、19世紀〜20世紀初頭の歴史的ステレオカード（Stereoview / Stereograph）のスキャン画像や、現代の2眼・チャチャ（Cha-Cha）ステレオ写真を、Core ML と 数理幾何最適化 によって自動復元・整準し、Apple Vision Pro 空間写真（MV-HEVC）や各種3Dフォーマットへ変換する macOS ネイティブスタジオアプリです。

開発初期段階のお知らせ： ViewStereo (v0.1.0) は現在アクティブに開発中の初期リリースです。すべての AI モデルはアプリに同梱されており、100% オフライン・オンデバイスで動作します。

2. 基本ワークフロー

  1. 画像を読み込む：スキャンしたステレオカード、左右ペア画像（L/R）、SBS画像、またはフォルダをキャンバスへドラッグ＆ドロップ（または ⌘O）。
  2. 自動検出 ＆ 整準：読み込み時に Core ML カード分割 → 7-DoF 対称ホモグラフィ整準 → カラーマッチング → ステレオウィンドウ最適化が自動実行されます（手動再実行は ⇧⌘A）。
  3. プレビュー確認：上部ツールストリップまたは ⌘1〜⌘8 で表示方式を切り替え、必要に応じて X キーで左右を入れ替えます。
  4. 微調整 / リマウント：インスペクターの STEREO WINDOW や STEREOVIEW CARD MOUNT で奥行き位置や台紙デザインを調整します。
  5. 書き出し：下部の Stereo Layout を選択し、⌘E で書き出します。

3. Core ML カード自動検出

BASIC RECIPE > STEREO CARD DETECTION で、スキャン画像からの左右写真切り出しを制御します。

  • Card Mode：
    • Off：現代の L/R ペアやトリミング済み SBS 画像用（カード検出スキップ）。
    • Crop Inner：台紙とアーチ枠を除外し、左右写真領域の有効矩形を抽出（推奨）。
    • Keep Arch (Black)：19世紀特有のアーチ型（Arch-top）枠を残したまま黒マスクで整準。
  • Core ML Card Segmentation (AI)：StereoCardSeg (U-Net) による自動領域・台紙輝度推定。
  • Segmentation Refiner：MobileSAM（高速・軽量）、SAM 2.1 Tiny（高精度・劣化カード向け）、U-Net Only から選択可能。
  • Card Frame：現代のステレオ写真にも Off / Rounded / Arch のクラシック枠を適用できます。

4. 7自由度ホモグラフィ & MAAIR

手貼りされた歴史的ステレオカード特有の傾き（ロール）、倍率差（スケール）、台形歪み（キーストーン）、上下ズレ（垂直視差）を、StereoCore の Accelerate LAPACK (dposv_) + IRLS によりサブピクセル精度で対称補正し、垂直視差をゼロ化します。

  • Vision Person Motion Mask (Cha-Cha)：チャチャ法で撮影した際、動いた人物を自動マスクし背景の静物を基準に正確に整準します。
  • Keep Original Aspect Ratio (MAAIR)：補正後の左右有効領域から黒枠を一切含まない最大面積の内接矩形（MAAIR）を自動算出してトリミングします。

5. ステレオウィンドウ調整

被写体が画面端で切れながら手前に飛び出す「ウィンドウバイオレーション」を防ぐため、最前景の視差から最適な水平シフト量（Auto: ○○ px）を自動計算します。

  • Vision Saliency Subject Priority：オンにすると Apple Vision の顕著性解析により主要被写体を優先してウィンドウを設定します。
  • Horizontal Shift (px)：スライダー・リセット・数値入力（-300.0〜+300.0 px）の3点セットで、ドラッグ中もリアルタイムに奥行き位置を微調整できます。

6. デジタル・リマウント & OCR

表示モードまたは書き出しレイアウトで Card（Stereoview Card） を選択すると、博物館品質のステレオカードとしてデジタル再構成できます。

時代別 Mount Style プリセット（8種類）

  • Original Mount (Remount) / Auto Sample Source Color
  • 1900s Keystone Dark（チャコール・曲面台紙）
  • 1880s Classic Buff（バフ黄褐色台紙）
  • 1870s Cabinet Terracotta / 1870s Victorian Green（バイカラー縁再現）
  • 1860s Chrome Yellow / 1850s Early Ivory（初期角丸なし・スクエア印画）

規格・印画カット・活版OCR

7インチ基準の Standard (7 × 3.5 in) / Cabinet (7 × 4.0 in) / Imperial (7 × 4.5 in)、印画カット（Arched Top / Rounded Corners / Square）、中央境界（Joined / Separated 3mm）を選択可能。さらに Vision OCR (Letterpress Auto OCR) が元カードの番号・下部タイトル・左右余白の出版社クレジットを自動認識し、活版印刷風タイポグラフィで綺麗に再印字します。

7. カラーマッチング & 復元

  • Auto Color Match：Off / Left Ref（左基準） / Right Ref（右基準）から選択し、左右の露光差や経年退色を自動整合します。
  • Remove Unilateral Noise & Dust：片側の写真にのみ存在するホコリ・傷・シミを自動低減します。

8. 立体視モード & 書き出し

8種類のプレビュー表示（2D / SBS / LR/RL / Dubois / Color Anaglyph / Gray Anaglyph / Polarized / Card）と、11種類の書き出しレイアウト（上記8種 + Separate L/R / Spatial Photo (HEIC / MV-HEVC) / MPO (3D Camera)）に対応しています。調整レポート（.txt）の保存も可能です。

9. フォルダ一括バッチ処理

⇧⌘B またはフォルダのドラッグ＆ドロップで大量のアーカイブを一括処理できます。ペアリング方式は Auto (L/R Pairs + SBS)、SBS Images Only、Consecutive L/R Pairs の3種類に対応し、出力先はデフォルトで <入力フォルダ>/ViewStereo_Output に生成されます。
