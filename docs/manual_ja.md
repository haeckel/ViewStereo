## 1. 概要とコンセプト

**ViewStereo（ビューステレオ）** は、19世紀から20世紀初頭にかけて制作された歴史的ステレオカード（Stereoview / Stereograph / Stereo Card）のスキャン画像、および現代の2眼カメラやチャチャ（Cha-Cha）撮影によるステレオ写真を、**Core ML** と **数理幾何最適化（7自由度対称ホモグラフィ）** によって自動検出・位置調整・ステレオウィンドウ最適化し、現代の鑑賞環境（Apple Vision Pro 空間写真、VR用SBS、アナグリフ、デジタル・リマウントカード等）へと復元・変換する macOS ネイティブスタジオアプリケーションです。

### Stereo Creative Studio シリーズにおける位置づけ
ViewStereo は、3D Gaussian Splatting の **SplatStereo**、2.5D 単眼AI深度の **DepthStereo**、360° 全天球パノラマの **PanorStereo** と同じ `StereoStudioCore` 共通基盤と Dark-First Studio UI を共有するファミリーアプリケーションです。テーマカラーは19世紀のセピア写真と真鍮製ステレオスコープを想起させる **アンバーゴールド（Amber Gold）** を採用しています。

## 2. システム要件とインストール

- **対応OS**: macOS 14.0 (Sonoma) 以降（macOS 15 Sequoia 対応）
- **ハードウェア**: Apple Silicon Mac（M1 / M2 / M3 / M4 シリーズ推奨）
- **メモリ**: 8 GB 以上（4K〜8Kの高解像度スキャンやバッチ処理には 16 GB 以上を推奨）

### インストール手順
1. 公式サイト（`https://viewstereo.p-media.jp/`）から `ViewStereo.dmg` をダウンロードします。
2. `ViewStereo.dmg` を開き、`ViewStereo.app` を `Applications`（アプリケーション）フォルダへドラッグ＆ドロップします。
3. アプリケーションフォルダから `ViewStereo.app` を起動します。

## 3. 画面構成（Dark-First Studio UI）

ViewStereo のウィンドウは、視認性と作業効率を両立した 2 ペイン構成です。

1. **上部ツールストリップ（Top Toolbar Strip）**
   - **立体視プレビューモード切替**: `2D` / `SBS` / `LR/RL` / `Dubois` / `Color Anaglyph` / `Gray Anaglyph` / `Polarized` / `Card` の8モードをワンクリックで切り替えます。
   - **左右スワップボタン（`X` キー）**: 交差法／平行法の反転や左右逆転したスキャンを即座に入れ替えます。スワップ中はキャンバス右上に `Swapped (R⇄L)` バッジが表示されます。
2. **メインプレビューキャンバス（Main Canvas）**
   - ステレオカード、左右ペア画像、SBS画像、またはフォルダを直接ドラッグ＆ドロップして読み込めます。
3. **右サイドバー・インスペクター（固定幅 400px / 大文字モード時 450px）**
   - **STATUS SUMMARY**: 現在の解像度、ホモグラフィ整準状態、自動ウィンドウシフト量などのテレメトリを表示します。
   - **STEREO WINDOW**: 水平シフト量（px）をスライダー・リセット・数値入力の3点セットでリアルタイム微調整します。
   - **STEREOVIEW CARD MOUNT**: デジタル・リマウントの時代別台紙プリセット、サイズ規格、印画カット、Vision OCR 活版タイポグラフィを設定します。
   - **BASIC RECIPE**: カード検出モード、Core ML リファイナー、自動整準AI、カラーマッチング＆ダスト除去を設定します。
   - **BATCH PROCESSING**: フォルダ単位の一括自動処理と調整レポート出力を行います。
   - **EXPORT FOOTER（固定フッター）**: 書き出し立体視レイアウト、画像フォーマット（JPEG / PNG / HEIC / MPO）、単体書き出しボタン、調整レポート保存ボタンを配置しています。

## 4. 基本的なワークフロー

1. **画像を読み込む**: スキャンしたステレオカード画像（または L/R 2枚の画像、SBS画像）をキャンバスにドラッグ＆ドロップ、または `⌘O` で開きます。
2. **自動検出＆整準**: 「Auto Align on Load」が有効な場合、読み込みと同時に Core ML カード分割 → 7-DoF ホモグラフィ整準 → カラーマッチング → ステレオウィンドウ最適化が自動実行されます。手動で再実行する場合は `⇧⌘A` を押します。
3. **プレビューで確認**: `⌘1`〜`⌘8` またはツールストリップで表示方式を切り替え、立体感やウィンドウの位置を確認します。必要に応じて `X` キーで左右を入れ替えます。
4. **微調整 / リマウント**:
   - 飛び出し量や奥行きバランスを調整したい場合は **STEREO WINDOW** の `Horizontal Shift (px)` を操作します。
   - 歴史的カードとして美しく再構成したい場合は `StereoView` / `Card` モード（`⌘1`）に切り替え、**STEREOVIEW CARD MOUNT** で台紙プリセットや OCR キャプションを調整します。
5. **書き出し**: 下部の **Stereo Layout** から出力形式を選び、`⌘E`（Export Image）で保存します。

## 5. Core ML ステレオカード自動検出・分割

19世紀のステレオカードは、台紙の上に左右2枚の印画紙が手作業で貼られており、上部がアーチ型（Arch-top）にカットされていたり、傾きや余白が不均一だったりします。

**BASIC RECIPE > STEREO CARD DETECTION** で以下の設定が可能です：

- **Card Mode**:
  - `Off`: 現代のデジタルステレオ画像やトリミング済みの L/R・SBS 画像に使用します（カード検出をスキップ）。
  - `Crop Inner`: 台紙とアーチ枠を除外し、左右の写真領域の最大内接矩形をクリーンに切り出します（標準推奨）。
  - `Keep Arch (Black)`: 19世紀特有のアーチ型上部フレームのシルエットを黒マスクとして残したまま整準します。
- **Core ML Card Segmentation (AI)**:
  - オンにすると、3段階カスケード台紙解析エンジン（`StereoCardMountAnalyzer`：スキャン余白分離＆水平化 → CIE Lab 台紙色バリア → 双子窓フィッティング）と内蔵 Core ML モデル（`StereoCardSeg` U-Net）が連携し、極細台紙枠や暗背景写真でも左右写真領域と台紙輝度を高精度に自動推定します。
- **Segmentation Refiner**:
  - `MobileSAM`: 高速かつ軽量なマスク精密化エンジン。通常のステレオカードスキャンに最適です。
  - `SAM 2.1 Tiny`: Meta AI の SAM 2.1 Tiny を用いた高精度リファイナー。色褪せや境界が曖昧なカードでも高精度に輪郭を抽出します。
  - `U-Net Only`: `StereoCardSeg` のみで超高速処理を行います。
- **Card Frame**（現代写真向けフレーム演出）:
  - `Off` / `Rounded`（角丸） / `Arch`（アーチ型）から選択し、現代のステレオ写真にもクラシックな額縁効果を与えられます。

## 6. 7自由度対称ホモグラフィ整準とMAAIR

歴史的ステレオカードでは、左右の印画の貼付角度のズレ（ロール）、撮影時のレンズ倍率差（スケール）、台形歪み（キーストーン）、上下のズレ（垂直視差）が頻繁に発生します。これらは目の疲労や立体視の破綻（網膜闘争）を引き起こします。

ViewStereo は `StereoCore` エンジンにより、左右画像を対称的に変形する **7自由度（7-DoF）対称ホモグラフィ最適化** を行います：
- Apple Accelerate の LAPACK (`dposv_`) と外れ値に強い **IRLS（反復再重み付け最小二乗法）** により、垂直視差をサブピクセル精度で実質ゼロに解消します。
- **Vision Person Motion Mask (Cha-Cha)**: 1台のカメラを横にずらして撮影する「チャチャ法」で人物がわずかに動いてしまった場合、Apple Vision で人物領域を自動マスクし、背景の静物のみを基準に正確に整準します。
- **Keep Original Aspect Ratio (MAAIR)**: 回転や台形補正後の左右有効領域から、黒枠（欠け）を一切含まない最大面積の軸平行内接矩形（Maximum Area Axis-aligned Inscribed Rectangle）を数学的に算出してトリミングします。

## 7. インテリジェント・ステレオウィンドウ調整

立体視において、被写体がフレームの左右端で切れているのに手前へ飛び出していると「ウィンドウバイオレーション」と呼ばれる強烈な違和感が生じます。

- **自動ウィンドウ決定**: 最前景（最近接被写体）の視差を解析し、飛び出しすぎず自然にフレームの奥に収まる最適な水平シフト量（`Auto: ○○ px`）を自動算出します。
- **Vision Saliency Subject Priority**: オンにすると、Apple Vision の顕著性（注目被写体）解析を組み合わせ、背景のノイズではなく主役となる人物や建造物を基準にステレオウィンドウを最適化します。
- **手動微調整（Horizontal Shift）**: スライダー、数値入力（`-300.0`〜`+300.0 px`）、リセットボタンの3点セットにより、ドラッグ中もリアルタイムでプレビューを確認しながら好みの奥行き位置へ調整できます。

## 7.5 古写真・退色階調復元 ＆ AI 光学デブラー（Vintage Photo Restoration）

経年劣化で色褪せたりピントが甘くなった歴史的ステレオ写真を、非破壊で鮮やかに復元します。
- **プリントトーン（Print Tone）**: `オリジナル (元色維持)` / `金調色鶏卵紙セピア (1860s)` / `ゼラチンシルバー調 (1890s)` / `純モノクローム` から選択可能。「1860年代 鶏卵紙プリセット」ボタンで当時の風合いをワンクリック適用できます。
- **自動黒締め・白抜き（Auto-Level %）＆ 局所コントラスト（CLAHE %）**: 退色して眠くなった黒と白の階調を引き締め、局所コントラストを復元します。
- **光学デブラー・輪郭復元（Optical Deblur %）**: 内蔵 Core ML モデル（`NAFNetDeblur`）により、歴史的レンズのぼけや経年劣化をAIで鮮鋭に復元します。
- **高周波・葉/粒子保護（Foliage / Texture Protection %）**: 木の葉や粒子など微細テクスチャの左右差による視野闘争（Retinal Rivalry）を防ぎます。
- **復元前と比較（Before）**: ボタン一つで復元前のオリジナル状態とリアルタイム比較できます。

### 手彩色風・AI カラー化（Hand-Tinted & AI Colorization）
内蔵 Core ML モデル（`StereoColorizer`）により、モノクロの19世紀ステレオ写真に自然な色彩や明治時代の手彩色風の色合いを加えることができます。
- **1890s 明治手彩色風 (透明水彩)**: 明治期の横浜写真・手彩色ステレオカードのような透明水彩調の優しい彩色を施します。
- **AI ナチュラルカラー化**: `StereoColorizer` がシーンに応じた自然なフルカラー化を100%オフラインで実行します。
- **既存手彩色の左右色ムラ同期 (Harmonize Existing Hand-Tint)**: すでに手彩色が施されたカードの左右眼の色ズレ・色ムラを同期します。
- **彩色・同期の強度 (%) / 鶏卵紙・染料の温かみ (%)**: 彩色の強さや温かみをスライダーで調整し、「カラー化を実行 / 解除」で切り替えできます。

## 8. デジタル・リマウント＆活版OCRタイポグラフィ

表示モードまたは書き出しレイアウトで **Stereoview Card（`Card`）** を選択すると、傷んだ台紙や切り出された左右写真から、博物館品質の美しいステレオカードをデジタル再構築（リマウント）できます。

### Mount Style（時代別台紙プリセット）
- **Original Mount (Remount)**: 元カードの台紙色と質感コンテキストを保持して再構成します。
- **Auto Sample Source Color**: 元カードの台紙色を自動サンプリングし、標準規格の綺麗な台紙として再生成します。
- **1900s Keystone Dark**: 1890〜1920年代の Keystone View Co. 等に代表されるチャコール・スレートグレー曲面台紙。
- **1880s Classic Buff**: 1880〜1890年代の温かみのあるバフ（黄褐色）台紙。
- **1870s Cabinet Terracotta**: 1870年代キャビネット判のテラコッタオレンジ（裏面ペールラベンダーのバイカラー縁再現）。
- **1870s Victorian Green**: 1870年代ヴィクトリアン・フォレストグリーン（ゴールド／バフのバイカラー縁再現）。
- **1860s Chrome Yellow**: 1860年代初期の鮮やかなクロームイエロー台紙。
- **1850s Early Ivory**: 1850年代黎明期のアイボリー・ブリストル紙（直角コーナー＆スクエア印画）。

### 規格・カット・テキスト設定
- **Card Size (7-inch Standard)**: `Standard (7 × 3.5 in)` / `Cabinet (7 × 4.0 in)` / `Imperial (7 × 4.5 in)`
- **Print Cut**: `Auto (Match Era)` / `Arched Top` / `Rounded Corners` / `Square`
- **Center Division**: `Auto` / `Joined (Seamless)` / `Separated (3mm)`
- **Mount Typography & Text**:
  - `Letterpress (Auto OCR)`: 元カードの台紙に印刷された番号（上部中央）、タイトル／キャプション（下部）、左右余白の出版社クレジット（縦書き）を Vision OCR で自動読み取りし、活版印刷風タイポグラフィで綺麗に再印字します。
  - `Letterpress (Manual)`: 任意の文字を手動入力して印字します。ファイル名をタイトルに流用するオプション（`Use Filename When Title Is Empty`）も搭載しています。
  - `No Text`: 文字なしのクリーンな台紙にします。

## 9. カラーマッチング＆ヴィンテージ復元

- **Auto Color Match**: 左右のレンズ特性差、現像ムラ、経年による片側だけの退色を自動補正します。
  - `Off` / `Left Ref`（左を基準に右を補正） / `Right Ref`（右を基準に左を補正）
  - インスペクター内の `Match Left` / `Match Right` ボタンで手動適用も可能です。
- **Remove Unilateral Noise & Dust**: 片方の画像にのみ存在するホコリ・傷・シミなどの局所的ノイズを自動検出して低減します。

## 10. 立体視プレビューモードと書き出し

### 8つのプレビューモード
1. `StereoView` (`⌘1`): デジタル・リマウントされたステレオカード表示
2. `SBS` (`⌘2`): 平行法 Side-by-Side
3. `LR/RL` (`⌘3`): 平行・交差両対応 4-Way レイアウト
4. `Dubois` (`⌘4`): 色再現性に優れたデュボア・アナグリフ（赤青メガネ用）
5. `Color Anaglyph` (`⌘5`): カラーアナグリフ
6. `Gray Anaglyph` (`⌘6`): 網膜闘争を抑えたグレースケール・アナグリフ
7. `Polarized` (`⌘7`): 偏光 3D モニター向けラインインターレース
8. `2D` (`⌘8`): 左目用の基準画像を単眼表示

### 11種類の書き出しレイアウト（`⌘E`）
上記8種類に加え、以下の専門フォーマットを出力できます：
- **Separate L/R**: 左右の画像を独立した2ファイル（`_L` / `_R`）として保存
- **Spatial Photo (HEIC)**: Apple Vision Pro の「写真」アプリでそのまま立体視できる **MV-HEVC 空間写真** を生成
- **MPO (3D Camera)**: 3D デジタルカメラ・3D フレーム標準の Multi-Picture Object 形式で保存

※ 右下のドキュメントアイコンボタンから、ホモグラフィ行列や視差・シフト量などの **調整レポート（`.txt`）** も保存できます。

### 動画 2D→3D 変換 ＆ 空間ビデオ書き出し（v0.1.9 新機能）
2D 動画（`.mp4` / `.mov` / `.m4v`）を読み込み、立体動画へ変換できます：
- **対応動画出力形式**:
  - **空間ビデオ (MV-HEVC .mov)**: Apple Vision Pro や iPhone 16 等で直接再生可能な空間メタデータ付き MV-HEVC
  - **Full SBS 3D (.mp4)** / **Half SBS 3D (.mp4)**: 各種 VR ゴーグルや 3D ディスプレイ向け
  - **アナグリフ 3D (.mp4)**: 赤青メガネでの鑑賞用
- **Apple Depth Pro 2 Stateful 深度推論**:
  - `MLState` による隠れ状態の保持により、動画特有のフリッカー（チラつき）を排除
  - 暗転・クールダウン付きシーンカット自動検出、時間的平滑化（EMA）、奥行きレンジ固定（Lock）
- **高速処理**:
  - Metal コンピュートシェーダー（`ViewStereoMetalDIBR`）によるゼロコピー GPU 3D 合成
  - AAC 256kbps 音声再エンコードと書き出し前空き容量チェックを搭載
- **SBS 動画片眼抽出**:
  - 既存の SBS 3D 動画から左眼または右眼を抽出し、再合成・リマスター可能

## 11. フォルダ一括バッチ処理

大量のステレオカード・アーカイブを自動で一括処理できます。

1. **BATCH PROCESSING** セクションを開くか、`⇧⌘B` を押します（フォルダを直接キャンバスへドロップしても開始できます）。
2. **Input Pairing** を選択します：
   - `Auto (L/R Pairs + SBS)`: フォルダ内の L/R ペア（ファイル名サフィックス自動認識）と単体 SBS / ステレオカード画像を自動判別してすべて処理
   - `SBS Images Only`: 単体画像（ステレオカード／SBS）のみを対象に処理
   - `Consecutive L/R Pairs`: 連番の連続する2枚を順番に L/R ペアとして処理
3. 必要に応じて **Save Adjustment Report (.txt)** をオンにし、出力先フォルダ（デフォルトは `<入力フォルダ>/ViewStereo_Output`）を指定して **Select Folder & Run Batch** をクリックします。
