# ViewStereo 今後の新機能・AI強化提案書（拡張統合版）

作成日: 2026-11-23（最終更新: 2026-11-24）  
対象アプリ: ViewStereo（macOS v0.1.9+）

---

## 1. 現状の到達点

現在の `ViewStereo` は、以下のコア機能がすでに揃っており、非常に高い完成度に達している。

- **ステレオカード自動検出・分割**: `StereoCardSeg` + `SAM 2.1 Tiny` による左右領域・アーチ枠の自動抽出
- **数理幾何・立体ウィンドウ最適化**: 7自由度対称ホモグラフィ最適化、MAAIR 最大共通内接矩形、インテリジェント・ステレオウィンドウ決定、擬似立体（Pseudoscopic）検出＆スワップ
- **片眼サルベージ ＆ 実視差較正**: 3大異常診断（貼り間違い・片側損傷・過大視差）および SIFT 実視差による単眼深度の線形較正
- **ヴィンテージ復元 ＆ AIカラー化**: 鶏卵紙/明治手彩色プリセット、片側ノイズ・ダスト除去、Auto-Level、CLAHE、`NAFNetDeblur` による光学デブラー、`StereoColorizer` による AI カラー化
- **2D→3D 写真＆動画変換**: 全9種の単眼深度エンジン（`StudioDepthEngine`）、Metal 1パス DIBR（`ViewStereoMetalDIBR`）、動画 Stateful 推論（`Depth Pro 2` の `MLState`＋シーンカット検出＋EMA平滑化）、Spatial Photo (HEIC) / Spatial Video (MV-HEVC) / MPO / SBS / LRRL / Dubois / Anaglyph / Polarized / Card 書き出し
- **ワークフロー**: フォルダ一括バッチ処理（自動ペアリング、警告時 2D→3D フォールバック）、ワークスペースファイルブラウザ

この土台を活かし、**「歴史的ステレオカードの修復・アーカイブ × 2D→3D 写真・動画変換 × Stereo Creative Studio エコシステム」** という `ViewStereo` 独自の強みをさらに伸ばすための新機能候補および構造的設計指針を以下に整理する。

## 2. 既存提案カテゴリ詳細（A〜D：修復・AIパイプライン・基本ワークフロー）

### カテゴリ A：歴史的ステレオカード・アーカイブ特化（独自価値の強化）

#### A-1. ステレオカード「裏面（Verso）」ペアリング ＆ OCRメタデータ自動埋め込み
- **概要**: 19世紀〜20世紀初頭のステレオカード（Underwood & Underwood や Keystone View 等）は、裏面に詳細な解説文・撮影年・撮影地・シリアル番号が印刷されている。
- **仕様イメージ**:
  - 表面（例: `*_front.jpg`）と裏面（例: `*_back.jpg` や連番画像）をペアで読み込み、Apple Vision OCR で解説テキスト・タイトル・出版年・撮影地・番号を自動抽出する。
  - 書き出す Spatial Photo（HEIC）や JPEG の **IPTC / EXIF / XMP メタデータ（Description / Keywords / Date / Location）へ自動埋め込み** する。
  - コレクション全体の検索可能なアーカイブカタログ（CSV / JSON / HTMLギャラリー）を出力可能にする。

#### A-2. ステレオ「相互補完（Cross-Eye Patching）」による物理損傷の修復
- **概要**: 現在は片側に大きな破れ・カビ・インク汚れがある場合、「片側を捨てて単眼 2D→3D サルベージ」を行う仕組みだが、「左の特定領域が破損しているが、右には同じ被写体が無傷で写っている」ケースも多い。
- **仕様イメージ**:
  - ホモグラフィ整準後の左右画像間で差分・異常領域（破れ・シミ・欠損マスク）を自動検出する。
  - **無傷な反対側の目から対応ピクセルを局所視差ワープで転写して穴埋め** する（両眼とも欠損している箇所のみ `LaMa` で補完）。
  - AI生成に頼りきらず、「撮影当時の本物のディテール」を維持した修復が可能になる。

#### A-3. ビフォー／アフター ワイプ比較 ＆ ウィンドウ違反ヒートマップ可視化
- **概要**:
  - **スプリットワイプ比較**: 退色補正・デブラー・AIカラー化・位置合わせの前後を、キャンバス上の縦線ドラッグで直感的に比較できるビュー。
  - **ウィンドウ違反（Window Violation）ヒートマップ**: 現在インスペクタのテキスト警告（`Detected (Edge)` 等）として通知しているウィンドウバイオレーションや過大視差箇所を、キャンバス上に半透明の赤／黄マスクでオーバーレイ表示し、どの被写体が枠に切れているかを一目で確認できるようにする。

### カテゴリ B：AI・画像処理パイプラインの高精度化

#### B-1. ニューラル特徴点マッチング（XFeat / LightGlue Core ML）の導入
- **背景**: 鶏卵紙や退色・低コントラスト・ハーフトーン（網点）印刷のステレオカードでは、古典的特徴量（SIFT等）が対応点を見つけられず誤整準や Mismatch 判定になることがある。
- **効果**:
  - 退色やノイズに極めて強い Core ML 版 XFeat または SuperPoint + LightGlue（FP16）を導入することで、難関カードの自動整準成功率を大幅に引き上げる。
  - `ViewStereoDepthSynthesizer.calibrateWithSparseStereo` における「実視差ガイド較正」のインライア数が増えることで、単なる全体の線形スケール合わせだけでなく、領域ごとの非線形深度較正への発展も可能になる。

#### B-2. `MPSImageGuidedFilter` ＋ `LaMa` による DIBR 境界と遮蔽補完の強化
- **背景**: `ViewStereoMetalDIBR` による高速な 1パス DIBR が稼働しているが、大視差を付けた際の背景の引き伸ばしや、低解像度深度モデル（504px〜518px）特有の輪郭の甘さをさらに詰められる余地がある。
- **効果**:
  - 元 RGB 画像をガイド画像とした `MPSImageGuidedFilter` を適用し、推論コストを抑えたまま髪の毛や枝などの深度境界をフル解像度へ復元する。
  - 静止画の最終書き出し時のみ **LaMa (`LaMaOutpaint.mlpackage`)** でディソクルージョン（手前の物体の裏側に生じた隙間）をインペイントする「高品位フィニッシュ」オプションを追加する。

#### B-3. StereoSpace v1.0（Depth-Free ステレオ直接生成）の試験導入
- **概要**: ガラス・水面・網・複雑な木の枝など、深度マップを介した DIBR では原理的に破綻しやすい被写体向けの救済・高品位生成モード。
- **効果**: Core ML 版 StereoSpace v1.0 を「AI Direct Stereo Generation」選択肢として追加し、DIBR との使い分けを可能にする。

#### B-4. AI 超解像（4K Upscale）
- **概要**: 古いステレオカードのスキャンや古い低解像度動画は画素数が不足しがちである。
- **効果**: 復元パイプラインの最終段に Core ML の軽量超解像モデル（Real-ESRGAN / SwinIR 等）を通し、Apple Vision Pro 等の高精細ディスプレイにも耐えうる **4K Spatial Photo / 4K Spatial Video** として書き出せるようにする。

### カテゴリ C：動画・出力フォーマットの拡張（写真と動画の体験統一）

#### C-1. ウィグルグラム（Wigglegram / GIF・ループ MP4）書き出し
- **概要**: 赤青メガネや VR ヘッドセットがない環境（SNS、Web、プレゼン資料）で、誰でも裸眼で立体感を体感できる **「左右交互切り替え／深度ベースの微小視点スイングアニメーション（GIF / ループ MP4）」** のワンクリック書き出し。
- **特徴**: ステレオ写真愛好家・アーカイブ公開用途で非常に需要が高く、既存の左右ペアおよび動画エンコード基盤をそのまま流用できるため実装コスト対効果が高い。

#### C-2. 動画の「リアルタイム 3D プレビュー再生」と「既存 SBS 動画の自動整準」
- **リアルタイム 3D プレビュー**:
  - 現在 `ViewStereoVideoProcessor` で動画の書き出しパイプラインが稼働しているが、書き出し前に `AVPlayerItemVideoOutput` → 非同期 Core ML 推論 → `ViewStereoMetalDIBR` をゼロコピーで繋ぎ、**視差強度やゼロ視差位置を調整しながらキャンバス上でリアルタイムに立体再生（アナグリフ / SBS）** できるようにする。
- **既存 SBS 動画の自動ホモグラフィ整準**:
  - 写真モードでは「ステレオ修復」と「2D→3D」の両方に対応しているのに対し、動画モードは現在「2D動画 → 3D」および「SBS片眼 → 2D→3D」に対応している。
  - 古い 3D ビデオカメラや DIY 2眼リグで撮影された **縦ズレ・回転ズレ・色差のある SBS 動画** を読み込み、写真と同じホモグラフィ整準＋カラーマッチングを適用して空間ビデオ（MV-HEVC）へ修復変換する機能を追加する。

#### C-3. Spot Focus Picker（クリックでゼロ視差面を指定）＆ 簡易深度ブラシ
- **概要**:
  - **Spot Focus Picker**: 2D→3D 変換時に、ユーザーがキャンバス上の「一番ピント（ステレオウィンドウ）を合わせたい被写体」をクリックするだけで `focusRatio` を自動設定するピッカー。
  - **簡易深度ブラシ**: 「空が手前に浮いた」「ガラスの奥行きがおかしい」といった AI 推定の局所的な外れを、手動でサッと塗って押し引き補正できるレタッチブラシ。

### カテゴリ D：ワークフロー・整理機能

#### D-1. フォルダ内の「バラバラ L/R ファイル」自動 AI ペアリング
- **概要**: 現在の `consecutiveLR`（連続ファイル）や SBS 判定に加え、ファイル名が不揃いなフォルダ内でも、特徴点類似度や撮影時刻メタデータから「同じシーンの左目と右目」を自動照合してペアリングするスマートペアリング機能。

#### D-2. リバーシブルなプロジェクトファイル保存（`.vstereo`）
- **概要**: ステレオカードの切り抜き枠、手動調整したホモグラフィ／ステレオウィンドウ値、復元レシピ、生成済み深度マップなどをバンドル保存し、後から再編集・別フォーマットへの再書き出しができる専用プロジェクト形式。

## 3. 追加独自提案（E〜I：5分野・15の新機能アイデア）

既存レポートのA〜Dに加え、**「歴史的ステレオ文化の体験価値」「実視差×AI深度の融合」「Trilogyアプリ連携」「立体視エルゴノミクス」「物理/展示アウトプット」** という新しい切り口からの提案。

### カテゴリ E：歴史的ステレオ文化・ミュージアム体験の拡張

#### E-1. 「2.5D パララックス・ケンバーンズ動画（Spatial Ken Burns Reel）」生成
- **概要**: 1枚の静止画ステレオカードから、仮想3Dカメラがゆっくりドリーイン（接近）やパン（横移動）を行いながら運動視差が変化する **5〜10秒の空間ビデオ（MV-HEVC）やSNS用MP4** を書き出す機能。
- **強み**: `ViewStereoMetalDIBR` と `ViewStereoVideoProcessor` を組み合わせるだけで実装でき、「150年前の静止画ステレオカードが動く空間ビデオとして蘇る」というキラーコンテンツになる。

#### E-2. 「カイザーパノラマ（Kaiserpanorama）／ホルムズ式ステレオスコープ」バーチャル覗き窓モード
- **概要**: 19世紀後半に欧州で流行した木製回転式立体覗き眼鏡「カイザーパノラマ」や「ホルムズ式ビューア」を模したフルスクリーン鑑賞モード。真鍮・木目の接眼レンズ枠、周辺減光（ビネット）、スペースキーで「カチャッ」と機械音を立ててワークスペース内の次のカードが回転送りされる体験。
- **強み**: `ViewStereo` の「View（鑑賞）」の名を体現するユニークな機能で、コレクターや博物館展示でのデモ効果が抜群。

#### E-3. 初期写真技法エミュレーション（ダゲレオタイプ／湿板アンブロタイプ／オートクローム）
- **概要**: 現在の「鶏卵紙（1860s）」「明治手彩色（1890s）」に加え、**「ダゲレオタイプ（銀板特有の鏡面メタリック階調）」**や、世界初の商業カラー写真技法**「リュミエール・オートクローム（1907年・三原色デンプン粒子の点描テクスチャ）」**への変換プリセット。

---

### カテゴリ F：実視差 × AI単眼深度の「ハイブリッド3D」＆ Trilogy連携

#### F-1. 「Stereo-Guided Dense Depth」実視差×AI深度の非線形フュージョンと RGB-D 書き出し
- **概要**: 現在は片眼サルベージ時のみ「SIFT実視差で単眼AI深度を線形較正」しているが、左右とも無傷なステレオカードでも **「実視差のスパース点群（幾何学的な絶対正解）＋ 単眼AI深度（髪の毛や輪郭の密な勾配）」を Thin-Plate Spline（TPS）等で非線形融合** し、実測ステレオに基づいた超高精度な **16-bit 深度マップ / RGB-D 画像** を生成・書き出し可能にする（`StereoStudioCore` の `RGBDImageCodec` を活用）。

#### F-2. Stereo Creative Studio Trilogy（SplatStereo / DepthStereo）へのワンクリック・ハンドオフ
- **概要**: 整準・復元したステレオペアや上記で生成した「実視差較正済み RGB-D」を、ワンクリックで兄弟アプリの **SplatStereo**（3D Gaussian Splatting による自由視点化）や **DepthStereo** に送る `Send to SplatStereo / DepthStereo` ボタン。
- **強み**: 4つのアプリが単なる共通UIではなく、ワークフローとして有機的に結合する。

#### F-3. 多視点キルト（Looking Glass）＆ レンチキュラー印刷用インターレース書き出し
- **概要**: 実視差で較正した深度マップと `ViewStereoMetalDIBR` を用い、左右2視点だけでなく **8〜45視点の連続視差画像（Looking Glass 用 Quilt 画像やレンチキュラーシート用インターレース画像）** を一発書き出しする機能。

### カテゴリ G：立体視エルゴノミクス ＆ 精密検品ツール

#### G-1. 「網膜闘争（Retinal Rivalry）検出ヒートマップ」＆ 鏡面ハイライト自動抑制
- **概要**: 古い銀塩プリントでは「左の写真だけ銀鏡化や折れ目で白飛びし、右は暗い」といった局所的な輝度不一致が起き、立体視した際にチカチカする「網膜闘争」が発生する。ホモグラフィ整準後の左右画像の局所コントラスト・輝度差（SSIM不一致）から**網膜闘争リスク箇所をヒートマップ表示し、片側だけの異常ハイライトを反対側の階調へ自動馴染ませる**機能。

#### G-2. フローティング「ステレオ比較ルーペ（Dual Stereo Loupe）」
- **概要**: キャンバス上でマウスホバーした局所領域（例: 200×200px）をフローティング小窓で4倍拡大し、**「左目・右目・差分（チェッカーボード/フリッカー）」を並べてサブピクセル単位の整準精度やデブラー効果を確認できるプロ用ルーペ**。その地点の水平視差（`+14.2 px / 1.8%`）と垂直誤差（`0.08 px`）もリアルタイム表示する。

#### G-3. 裸眼立体視サポート「フュージョン・ガイドドット」＆ 実寸IPD（65mm）表示幅ロック
- **概要**: `SBS` や `LR/RL` モードで裸眼立体視（平行法・交差法）をする際、画像の上部中央に視線融合を助ける「ガイドドット（●）」を表示するオプション。さらにMacの画面PPIを取得し、**「平行法で目が外側に開かず楽に立体視できる物理幅（左右の中心間距離 ≦ 60〜65mm）」にキャンバスのズーム倍率をワンクリックで合わせる `1:1 IPD Zoom` ボタン**。

### カテゴリ H：物理クラフト出力 ＆ デジタルアーカイブ展示

#### H-1. 実寸ステレオカード「トンボ付き印刷用 PDF（両面・300/600 DPI）」書き出し
- **概要**: デジタルリマウント機能で作ったステレオカード（Standard 7×3.5 inch 等）を、自宅のプリンタや印刷所で厚紙に印刷し、**本物の19世紀アンティーク・ステレオビューアに差し込んで覗けるよう、実寸サイズ＋裁断トンボ（Crop Marks）＋裏面（Verso解説テキスト）付きPDF** として書き出す機能。

#### H-2. WebXR / Vision Pro Safari 対応「スタンドアロン 3D アーカイブ HTML ギャラリー」生成
- **概要**: バッチ処理完了時に、出力フォルダ内に単体で動く `index.html` ギャラリーを生成。OCRで抽出したカードタイトル・番号で検索でき、ブラウザ上で **Anaglyph / SBS / Wiggle / 比較スライダー** を切り替えて閲覧できる機能（コレクターが自分のアーカイブをそのままWeb公開・配布可能）。

#### H-3. コンタクトシート（一覧カタログ画像 / PDF）書き出し
- **概要**: ワークスペース内の数十枚のステレオカードを、サムネイル＋OCRタイトル＋視差統計バッジ付きの一覧シート（グリッド画像またはPDFカタログ）として出力するアーカイブ管理機能。

### カテゴリ I：macOS / visionOS エコシステム統合

#### I-1. 「写真.app」の空間アルバムへ直接登録 ＆ AirDrop to Vision Pro ボタン
- **概要**: ファイルとして書き出すだけでなく、ツールバーからワンクリックで `PHPhotoLibrary` を介して macOS の「写真.app」へ空間写真（Spatial Photo）/ 空間ビデオとして追加、または `NSSharingService` で **Apple Vision Pro へ直接 AirDrop 送信** するショートカット。

#### I-2. 統計テレメトリのビジュアルゲージ化（Percival Comfort Zone メーター）
- **概要**: 現在テキストで表示している `Window Shift` や視差範囲を、インスペクタ内に **「Percivalの快適視差ゾーン（-1% 〜 +2.5%）に対して現在の最前景〜最背景の視差ヒストグラムがどこに収まっているか」を示すミニグラフ（Depth Budget Meter）** として可視化。飛び出しすぎ・奥まりすぎが直感的に分かる。

#### I-3. プリセット＆復元レシピのクリップボード共有（`StudioPresetClipboard` 連携）
- **概要**: `StereoStudioCore` に用意されている `StudioPresetClipboard` を活用し、お気に入りの「ヴィンテージ復元＋カラー化＋リマウント台紙設定」をJSONテキストとしてコピー＆ペースト、または他ファイルへ一括ペースト（`⌥⌘C` / `⌥⌘V`）できる機能。

## 4. 構造的課題とアーキテクチャ設計指針

v0.1.9 時点の各仕様書とソースコード構造（全約20,670行）を横断的に分析すると、次期フェーズ（v0.2.0 以降）へ進むために解決すべき **4つの構造的ギャップ** と、それを支える **4つのアーキテクチャ設計指針** が導き出される。

### 4.1 次に解くべき4つの構造的ギャップ

1. **難関画像・片側損傷に対する「実写ディテール維持」の限界**
   - 退色・低コントラスト・網点印刷のステレオカードでは、古典的特徴量（SIFT等）が対応点を見つけられず誤整準や不一致判定になる場合がある。
   - 片側に大きな破損がある場合、現状は「片側を捨てて単眼 2D→3D サルベージ」を行う設計だが、反対側の目に無傷の被写体が残っているケースの活用がまだできていない。
2. **DIBR 合成の境界品質と微調整手段の不足**
   - 低解像度深度モデル（504px〜518px）特有の輪郭の甘さや大視差時の背景引き伸ばし、動画におけるオクルージョン境界の微細なジリつき、ガラス・水面・木の枝など深度マップ経由の DIBR では原理的に破綻しやすい被写体への対策に伸びしろがある。
   - また、AI 推定の局所的な外れ（空の浮き等）を手動でサッと修正する手段がない。
3. **静止画と動画の体験差・検品UIのテキスト依存**
   - 写真モードでは「ステレオ修復」と「2D→3D」の両方に対応しているのに対し、動画モードは現在「2D→3D」と「SBS片眼抽出→2D→3D」に留まっており、既存 SBS 動画の自動ホモグラフィ整準が未対応である。
   - ウィンドウ違反や視差レンジのテレメトリがインスペクタ上のテキスト警告中心であり、キャンバス上で「どこが破綻しているか」を直感的に把握する視覚化が不足している。
4. **アーカイブ運用とエコシステム連携の未完結**
   - 作業途中の枠・整準値・復元レシピ・深度マップを保持して再編集できるプロジェクト形式がなく、歴史的カードの裏面（Verso）にある解説・撮影年・撮影地といった一次資料情報も未統合である。
   - Stereo Creative Studio ファミリー（DepthStereo / PanorStereo / SplatStereo）とは Core ML モデルのローカル共有まで実現しているが、アプリ間の直接的なデータ連携（ハンドオフ）は未実装である。

### 4.3 実装アーキテクチャ設計指針（技術的負債を防ぐ4つの原則）

#### 指針1：「個別の機能追加」を「1本の統合ハイブリッド深度エンジン」に束ねる
「XFeat/LightGlue導入（B-1）」「ステレオ相互補完 Cross-Eye Patching（A-2）」「2.5D ケンバーンズ空間動画（E-1）」「実視差×AI深度の RGB-D 生成＆SplatStereo連携（F-1, F-2）」は別々の機能として実装するのではなく、**1つの共通基盤（Stereo-Guided Dense Disparity Engine）** として統合設計する。

| ステップ | 処理内容 | 役割 |
| :--- | :--- | :--- |
| **Step 1** | 密な特徴点対応（SIFT / XFeat / LightGlue） | 幾何学的に絶対正しい実視差アンカー点群（Sparse）を取得 |
| **Step 2** | 単眼 AI 深度推論（Depth Pro 2 / MoGe-2） | 輪郭や細部が滑らかで密な相対深度勾配（Dense）を取得 |
| **Step 3** | 非線形フュージョン（Thin-Plate Spline 等） | **【中核】実視差較正済み Dense Disparity Map** を生成 |
| **派生出力** | ① Cross-Eye Patching（反対目からの傷転写）<br>② 2.5D Ken Burns / Wiggle 自由視点動画<br>③ 16-bit RGB-D 出力（SplatStereo 連携） | 中核マップ1つからすべての高次機能を最小コード量で派生させる |

#### 指針2：UI肥大化の防止（「インスペクタを増やさず、キャンバスHUDへ逃がす」）
- 右インスペクタ（400pt固定幅 Anti-Jitter UI）には `⌥⌘1`（基本）〜 `⌥⌘6`（バッチ）の**「パラメータ（数値・レシピ設定）」だけを置く原則**を徹底する。
- 検品ヒートマップ、深度ブラシ、裏面OCR、動画編集などの追加に伴うインスペクタの過密化を防ぐため、コンテキストに応じたパネル表示切替と「基本／詳細」の階層整理を維持する。
- **ワイプ比較スライダー、ウィンドウ違反／網膜闘争ヒートマップ、ステレオ比較ルーペ、1:1 IPD ズーム、Spot Focus Picker** といった「視覚検品・直接操作系ツール」は、右インスペクタではなく **中央キャンバスのフローティングHUDバー（オーバーレイピル）** に集約する。

#### 指針3：メモリ管理と `.vstereo` 非破壊保存（ハイブリッド・サイドカー方式）
- Depth Pro 2 Large（ピーク 4.0 GB）や NAFNetDeblur・StereoColorizer に加え、今後 XFeat・LaMa・4K超解像などの Core ML モデルが増えるため、自動メモリ解放機構（`releaseAIModelsAfterGeneration`）のさらなる最適化と並行して、途中状態を安全に退避できる `.vstereo` 基盤の優先度を早めに引き上げる。
- 数百枚のステレオカードを扱うアーカイブ作業のリズムを止めないよう、以下の **ハイブリッド2段方式** を採用する。
  1. **日常のワークスペース作業（自動サイドカーキャッシュ）**: 調整した切り抜き枠・7-DoF行列・復元レシピ・量子化深度キャッシュを `.vstereo_cache/<filename>.vstereo.json` へ自動保存し、別ファイルから戻った際に再推論ゼロ（0.1秒）で状態を復元する。
  2. **アーカイブ配布・バックアップ（`.vstereo` バンドル書き出し）**: 明示的にプロジェクト書き出しを選んだ時のみ、元画像＋裏面OCR＋深度マップ＋レシピを単一の `.vstereo` パッケージ（macOS Package Directory）として出力する。

#### 指針4：約2万行に達したコードベースのモジュール分割と `StereoStudioCore` 昇格
現在、`ViewStereoModels.swift`（約6,900行）、`StereoCardSegmenter.swift`（約5,100行）、`ContentView.swift`（約3,350行）の3ファイルにロジックが集約されている。Step 1 の機能追加に着手するタイミングで以下の責務分割を行うことで、プレビューキャッシュとフル解像度書き出しキャッシュの整合性および保守性を高める。
- **`ViewStereoModels.swift` の分割**:
  - `ViewStereoAlignmentEngine.swift`（7-DoF整準・異常診断・ウィンドウ計算）
  - `ViewStereoRestorationEngine.swift`（鶏卵紙トーン・CLAHE・NAFNetデブラー・StereoColorizer）
  - `ViewStereoRemountEngine.swift`（デジタルリマウント・Vision OCR組版）
  - `ViewStereoExportManager.swift`（マルチフォーマット出力・Wiggle・バッチ処理）
- **`StereoStudioCore` への共通コンポーネント昇格**:
  - **Depth Budget Meter（視差コンフォートメーター）**、**Wigglegram / Ken Burns エクスポーター**、**写真.app / Vision Pro AirDrop 連携** は `StereoStudioCore` 側に実装し、`DepthStereo` や `SplatStereo` を含む Trilogy 全体の共通資産とする。
