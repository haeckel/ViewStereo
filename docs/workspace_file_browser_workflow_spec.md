# ViewStereo 作業工程・3ペインファイルブラウザ仕様書

## 1. 概要と目的
ViewStereo の基本ワークフローを「単発ファイル／バッチフォルダの都度ダイアログ選択型」から、**「作業フォルダを起点とした 3 ペイン・スタジオ型ワークフロー（左：ファイルブラウザ ｜ 中央：映像プレビュー ｜ 右：ツールパレット）」** へ再設計する。

これにより、以下のサイクルを Finder へ戻ることなくアプリ内でシームレスに完結させる：
1. アプリ起動時に作業フォルダを指定し、左ペインのファイルブラウザへ展開する。
2. ファイルブラウザで 1 項目をダブルクリックして単体処理・レシピ調整を行う。
3. 複数ファイルまたはフォルダを選択してバッチ処理を実行し、中央プレビューでライブ結果を確認する。
4. バッチ結果のステータス／警告バッジ（`✓` / `⚠️` / `✕`）を確認し、異常があった画像だけをダブルクリックして個別修正（左右スワップ・単眼3Dサルベージ・ウィンドウ微調整・クイック書き出し）を行う。

## 2. 画面構成（3 ペイン Anti-Jitter Studio UI）

| ペイン | 役割 | レイアウト・幅仕様 | 開閉制御 |
| :--- | :--- | :--- | :--- |
| **左ペイン** | **ツリー型ファイルブラウザ** | 既定 `260pt`（大文字モード `290pt`）、ドラッグリサイズ可（`220〜360pt`）、Anti-Jitter 固定幅ルール準拠 | 常時表示（ツールバー左端 `sidebar.left` / `⌥⌘L` で開閉可） |
| **中央ペイン** | **映像プレビュー専念** | 可変幅（`.infinity`）。単体プレビューおよびバッチ実行中のリアルタイムプレビューを表示。従来の排他 `batchQueueCanvasView` は廃止 | 常時表示 |
| **右ペイン** | **ツールパレット（インスペクター）** | 固定幅 `400pt`（大文字モード `450pt`）、Anti-Jitter 4層固定幅ルール準拠 | ツールバー右側 `sidebar.right` / `⌥⌘0` で開閉可 |

- **ウィンドウサイズ**: 既定 `1440 × 860`、最小 `1180 × 680`。

## 3. 工程別仕様

### 3.1 起動時のフォルダ選択フロー
- **シート表示**: メインウィンドウ表示後、`NSOpenPanel.beginSheetModal(for: window)` で作業フォルダ選択シートを表示する。
  - `directoryURL` の初期位置は前回開いたフォルダ（未設定時はピクチャまたはホーム）。
  - シート下部の `accessoryView` にて **処理モード（`Stereo 修復`［2D自動判定を含む］／`2D → 3D`［検証なし高速変換］）** をフォルダと同時に選択でき、前回モードの意図しない引きずりを防止する。
- **競合・二重モーダル回避**:
  - `StudioUpdateNotificationSheet` とは排他制御し、同時表示を避ける。
  - Finder から画像やフォルダをドロップ／「このアプリケーションで開く」で起動した場合は起動時シートを抑止し、その親フォルダ（またはフォルダ自体）をブラウザに開いて当該画像を即座に読み込む。
- **キャンセル時**:
  - 左ブラウザを空状態（ウェルカム導線：「フォルダを開く」「最近開いたフォルダ一覧」）とし、中央にランディングビューを表示する。
- **設定画面（General）の起動時動作オプション**:
  - `起動時にフォルダ選択シートを開く`（**既定**）
  - `前回開いていたフォルダを自動で開く`
  - `何もしない（ウェルカム画面を表示）`

### 3.2 ツリー型ファイルブラウザ仕様（左ペイン）
- **ヘッダー**:
  - 現在のルートフォルダ名、フォルダ変更ボタン（`⇧⌘O`）、再読み込みボタン。
  - 表示切替：**コンパクトリスト**（小サムネイル＋ファイル名） ⇔ **大きめサムネイル表示**。
  - 検索フィルタ（ファイル名部分一致）＋ **「⚠️ 警告・エラーのみ」フィルタ**。
- **階層ツリー＆遅延スキャン**:
  - サブフォルダをディスクロージャで展開表示。展開時に遅延スキャンを行い、Google Drive 等の大量ファイル環境でも UI ブロッキングを防ぐ。
  - 対応画像拡張子のみを表示し、非対応ファイル（`.txt`, `.DS_Store` 等）は非表示。
  - サムネイルは `CGImageSourceCreateThumbnailAtIndex` により非同期生成し、`NSCache` でキャッシュする。
- **L/R 別ファイルペア自動統合**:
  - `_L`/`_R`、`-L`/`-R`、`_left`/`_right`、`Left`/`Right` 等の命名規則を自動検出し、ブラウザ上で **`baseName`（`L+R` バッジ付き）の 1 項目に自動統合**して表示する。
  - 統合項目をダブルクリック／`Return` すると L/R ペアとして読み込む。
- **出力フォルダ（`ViewStereo_Output`）の保護**:
  - 出力先フォルダは専用バッジ／アイコンで識別表示し、**バッチ処理の入力スキャンからは常に自動除外**する（二重処理事故の防止）。
- **操作状態の分離**:
  - **選択中（Selected）**: シングルクリック／`⌘` 複数選択／`Shift` 範囲選択／フォルダ選択。ティール系ハイライト。重い解析は実行しない。
  - **編集中（Active）**: ダブルクリック（または選択して `Return`）で中央プレビューに開いている項目。アンバーゴールドのインジケータバーで明示。
- **処理ステータスバッジ**:
  - 各行に `処理中` / `✓ 完了` / `⚠️ 警告（偽視・片側損傷・不一致・視差過大）` / `✕ 失敗` を表示し、バッチ後の検品と個別修正へ直結させる。

### 3.3 バッチ処理の対象範囲と操作
- **選択状態に応じたバッチ対象解決**:
  - **複数ファイル（ペア含む）選択時**: 選択されたアイテムのみを処理。
  - **フォルダ選択時**: 選択フォルダ**直下の対象ファイルのみ**を処理（既定）。
  - **混在選択時**: URL 正規化による重複排除後の和集合を処理。
  - **未選択時**: ルートフォルダ直下を対象とする。
- **サブフォルダ再帰オプション**:
  - 右インスペクター `BATCH PROCESSING`（`⌥⌘6`）に **「サブフォルダを再帰的に含める」トグル（既定 OFF）** を配置。
  - 再帰 ON 時は出力フォルダ側でも相対サブフォルダ構造を維持（`ViewStereo_Output` は除外）。
- **下部アクションバー＆コンテキストメニュー**:
  - 選択内容と件数をリアルタイム表示した実行ボタン（例：`選択 12 件をバッチ実行` / `フォルダをバッチ実行 (28件)`）。
  - 未ペア単体画像がちょうど 2 件選択されている場合は、「L/R ペアとして開く」アクションも選択可能にする。

### 3.4 ワークフロー補助機能（状態整合性）
1. **レシピ維持オプション（Keep Recipe Across Images）**:
   - 次の画像を開いた際、ヴィンテージ復元・カラー化設定をリセットせず維持できるトグルを追加（既定では OFF または切替可）。
2. **未適用（Pending）設定のバッチ反映**:
   - スライダーや設定を変更して「Apply」を押す前にバッチを実行した場合でも、現在の UI 設定値をバッチ用スナップショットへ反映する。
3. **クイック書き出し（`⇧⌘E`）**:
   - 右下フッターに、ダイアログなしで現在の作業フォルダの出力先（`ViewStereo_Output`）へ即保存する「クイック書き出し」ボタンを追加し、保存後にブラウザ行へ `✓` ステータスを反映する。
4. **処理中ガード**:
   - 単体解析中・バッチ実行中は競合操作を安全にロックし、完了時に出力フォルダのツリー表示を自動リフレッシュする。

## 4. ステレオチェック後のバッチ警告ポリシー ＆ 2D 自動判定 3D 変換仕様

### 4.1 バッチ警告ポリシー（4 モード）
右インスペクター `BATCH PROCESSING` に **「警告ファイルの扱い（On Stereo Warning）」** を設ける。事前のステレオ検証の有無にかかわらず同一ルールで動作する。

| モード | 正常ファイル (OK) | 警告・整準失敗ファイル (⚠️ / ✕) |
| :--- | :--- | :--- |
| **すべて通常通り書き出す** | True Stereo 出力 | True Stereo 出力（失敗時はスキップ） |
| **警告ファイルを除外して書き出す** | True Stereo 出力 | **スキップ**（ブラウザ上に ⚠️ を維持） |
| **警告を 2D-3D 変換して書き出す** | True Stereo 出力 | **AI 2D-3D 変換して `_2D3D` 付きで出力** |
| **警告のみ 2D-3D 変換して書き出す** | **スキップ** | **AI 2D-3D 変換して `_2D3D` 付きで出力** |

- **変換対象**: ステレオ不成立・片側大面積損傷・視差過大・**特徴点不足等の整準失敗**を対象とする（左右逆は自動スワップで True Stereo 修復可能なため対象外）。
- **出力先とファイル名**: 通常と同じ `ViewStereo_Output/` フォルダに出力し、2D-3D 変換したファイルのみ末尾に `_2D3D` サフィックスを付与する（例: `name_2D3D_Card.jpg`）。
- **バッチ時の深度パラメータとメモリ**: 優先 AI 深度エンジンと `Virtual Baseline (%)`（既定 `3.0%`）／`Depth Gamma`（既定 `1.0`）を使用し、バッチ中はモデルキャッシュを保持して完了後に一括解放する。
- **手動編集**: 単体オープン時は自動変換せずユーザー判断に委ね、画面上の 3D 変換状態のまま `Quick Export` / `Export...` で書き出せる。

### 4.2 2D ファイル自動判定 ＆ 3D コンバージョン
単一画像を開く際（単体・バッチ共通）、入力モード（`Auto` / `Force Stereo` / `Force 2D → 3D`）に応じて自動判定を行う：
1. MPO / 空間写真 HEIC / L+R 2ファイル → **3D (Stereo)**
2. ステレオカード台紙＋左右パネルが有効に検出された場合 → **3D (Stereo Card)**
3. アスペクト比 `W/H < 1.15`（縦長・正方形） → **2D Photo**
4. 横長単一画像 → 中央境界 (`x = W/2`) の垂直不連続性と左右半分の SIFT 水平一致数・NCC 相関を評価し、一致がなければ **2D Photo** と判定。
5. **2D Photo 処理**: 分割せずフル画角のまま AI 深度推定 → DIBR 合成を行い、ブラウザ上に `2D→3D` バッジを表示する。

## 5. 2D → 3D 専用モード（`2D → 3D` Workspace Mode）

ステレオ写真修復を行わず、通常の 2D 画像を高速かつ直感的に 3D 変換するための専用作業モードを設ける。

### 5.1 モード切替と処理パイプライン
- ツールバーに **`[ Stereo 修復 | 2D → 3D ]`** のモード切替スイッチを配置する。
- **`2D → 3D` モード時の挙動**:
  1. **高速最短ルート**: ステレオカード分割・SIFT 特徴点抽出・2D 自動判定・7-DoF 整準・ステレオ検証をすべてスキップし、フル画角のまま AI 深度推定 → DIBR 3D 合成を実行する。
  2. **ファイルブラウザ最適化**: `_L` / `_R` の自動ペア統合をオフにし、1 ファイル ＝ 1 枚の 2D 画像として表示する。「ステレオ検証」ボタンは非表示とし、バッチ実行ボタンを **`2D → 3D 一括変換`** に一本化する。
  3. **右ツールパレット最適化**:
     - ステータス欄に「AI 深度エンジン」「推論時間」「ステレオベース (%)」を表示する（垂直視差 RMSE・ステレオ警告は非表示）。
     - 最上部に **`2D → 3D CONVERSION`** パネルを配置し、AI 深度エンジン選択、**ステレオベース (`%`)**、**奥行きオフセット (`px` / 飛び出し位置)**、**深度ガンマ** の 3 点セット調整を提供する。
     - 台紙設定・退色復元・手彩色 AI カラー化・各種 3D 書き出しはそのまま連携して利用できる。
